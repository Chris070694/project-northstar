INSTALLATION
1. ZIP vollständig entpacken.
2. Supabase → SQL Editor → oben auf + / New Query.
3. 03_NORTHSTAR_V033_ACADEMY_CALENDAR.sql vollständig einfügen.
4. Run drücken und auf Success warten.
5. Deine funktionierende config.js aus v0.3.2 in diesen Ordner kopieren.
6. index.html öffnen.

WICHTIG
- Die PWA-Installation funktioniert zuverlässig, sobald die App über Vercel online läuft.
- Lokal über file:// funktioniert die App, aber der Service Worker wird aus Sicherheitsgründen nicht installiert.
- Alle bisherigen Daten bleiben erhalten.
